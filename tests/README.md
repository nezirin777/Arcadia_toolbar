# ブラウザ回帰テスト

`browser-runner.html` は、`fixtures/` の合成HTMLへ現行Userscriptを注入して確認する、依存パッケージ不要のテストランナーです。

## 実行方法

1. このリポジトリをApacheなどのHTTPサーバーから配信する。
2. ブラウザで `tests/browser-runner.html` を開く。
3. 「全テスト実行」を押す。
4. すべての行が `OK` になったことを確認する。

SS本文の体裁整形は `ss-article-formatting.html` を使い、空行圧縮、字下げ、不要改行除去、連字折返し、会話境界への空行挿入、全解除時の原文復元を個別に確認します。整形同士の処理順と、属性・既存要素を変更しないことも確認対象です。

目次ポップアップは、表示状態とボタンの `aria-expanded` が開閉操作に合わせて一致すること、および非表示アニメーション中の再表示が後発タイマーで取り消されないことを確認します。

感想ページのページネーション置換では、先頭の旧ページリンクだけを削除し、感想本文内にある `page` 付きの通常リンクを保持することを確認します。

保存データの試験では、破損JSONからの復旧と、既知設定の異常型だけを既定値へ戻す再帰マージを確認します。

一覧リンクの最適化は、テスト板リンク削除時に文字だけでなく空アンカーも残らないことを確認します。

お気に入りのインポートは、メモ内に区切り文字 ` // ` が含まれても後半を欠落させず保持することを確認します。

お気に入り管理画面は、初回クリックで表示され、その後のクリックでも表示・非表示を正しく切り替えられることを確認します。

お気に入り検索は、Escapeキーで検索結果、入力値、強調表示、クリアボタンをまとめて解除することを確認します。

検索バーは、3種類のフォーム、パネル開閉、現行のHTTPS送信先、空入力の送信防止を確認します。

スパム非表示はURL文字列を含む合成行だけを隠し、通常の英語タイトルを残すことを確認します。設定リセットは保存済み設定を削除し、画面上の入力欄も既定値へ戻すことを確認します。

設定スキーマは、設定画面へ公開する全37項目が欠落せず、リセット後の入力値と保存値が既定値に一致することを確認します。

お気に入りのテキスト変換は、`FavoritesCodec`がDOMやlocalStorageを変更せず、バックスラッシュ・区切り文字・複数行メモを含む既存形式を往復保持することを確認します。

一覧の非同期更新は、40件を超える合成行の初期描画中にお気に入り更新を割り込ませ、古い世代のチャンク処理を中断して最新世代だけを各行へ適用することを確認します。

機能レジストリは、ページ種別・`act`・設定値ごとの起動対象を固定し、ライフサイクル終了時にFeatureと共有購読を逆順かつ一度だけ破棄することを確認します。全テストでbfcache退避相当の`pagehide`後もUIと購読を保持し、復帰相当の`pageshow`で二重初期化しないことも確認します。

体裁バーの責務分離は、`ArticleContentFormatter`がUIなしで本文を整形・原文復元できることと、`StyleBarState`が保存値を書き換えずにスタイル選択肢と整形フラグを正規化できることを確認します。

PV列のないチラシの裏一覧では、PV率表示と低PV率非表示を有効にしても記事数・全話リンク・行表示を維持することを確認します。

チラシの裏一覧の初期描画中にお気に入り更新が割り込んでも、感想セルを1個だけ生成することを確認します。

お気に入りの書き出しと再インポートでは、複数行メモを字下げした継続行として表現し、改行と区切り文字を含む内容を欠落させず復元することを確認します。

お気に入りタイトル内の区切り文字 ` // ` は書き出し時にエスケープし、元から含まれるバックスラッシュと区別してタイトル全体を復元することを確認します。

テーマ切替は、DOM・保存値の更新に加えて、内部更新通知が1操作につき1回だけ発火することを確認します。

別タブからの保存変更は、ネイティブの `storage` イベントを通じてお気に入り一覧・管理画面とテーマ表示へ反映されることを確認します。

お気に入りインポートは、空・未認識の入力が既存データを消去しないことと、有効な合成データは正しく置換・保存されることを確認します。

お気に入り検索中の追加・インポートは、保存後も入力済みの検索条件で一覧を再計算することを確認します。

初回利用時の追加と、同一カテゴリ内の同名項目を再追加・インポート・読込したときの一意化も確認します。お気に入りのメモは最後の内容を採用します。

保存済みお気に入りの型検証では、数値タイトルや空白だけの項目を除外し、前後空白とメモの異常型を正規化して例外なく起動できることを確認します。

設定編集は色コードや数値の入力途中値を保持し、保存時に型検証した値をlocalStorageと画面の両方へ再反映することを確認します。

色コード検証はテーマの文字色・背景色だけへ適用し、`#` で始まる投稿者名・トリップ・パスワードを通常の文字列として保存できることを確認します。

設定画面の項目網羅性は、一覧の行間調整と本文の標準フォントを画面から変更・保存できることを確認します。

体裁バーの専用保存値は、スタイル選択肢と整形フラグをキー単位で検証し、不正・欠落値を標準値へ補完して本文DOMへ適用することを確認します。

`file://` から直接開くと、ブラウザの制限によりUserscript本体を読み込めません。

## 安全性

- 実サイトへ通信しません。
- 作品名、本文、投稿者、IDはすべて合成値です。
- テスト中は同一オリジンのlocalStorageへ検証用設定を一時保存します。
- 実行前の対象キーは退避し、終了時に復元します。
- npm、build、ESModulesは使用しません。
