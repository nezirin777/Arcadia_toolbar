# ArcadiaToolBar Next

ArcadiaのSS・メイン・捜索掲示板を読みやすくし、お気に入り管理や投稿補助を追加するUserscriptです。

## 配布対象

- 現行版: `Arcadia_toolbar_next.js`（バージョン5.02）
- 旧版参照用: `Arcadiaツールバー.js`（比較専用・インストール不可）

旧版参照ソースには新規インストール用のメタデータがありません。旧版を既に登録している場合は、画面再構築やイベントの二重実行を防ぐため無効化し、現行版だけを有効にしてください。

## 主な機能

- SS一覧、メイン掲示板、捜索掲示板の表示整形
- タイトル部分一致によるお気に入り色分けとNG非表示
- 全話・感想ページへの直リンク
- 単話・全話表示の目次と本文スタイル調整
- 感想の新着順表示、日本語日付、ページリンク
- お気に入りの追加、検索、インポート、エクスポート
- 任意設定による投稿者名、トリップ、パスワードの自動入力

## インストールと更新

1. Userscriptを実行できるブラウザ拡張を用意する。
2. `Arcadia_toolbar_next.js` の内容を新しいUserscriptへ登録する。
3. 旧版を登録済みの場合は、旧版を無効化する。

更新前には、お気に入り管理画面の「エクスポート」で登録内容を控えてください。

## 保存データ

設定はArcadiaと同じオリジンのlocalStorageへ保存します。

| キー | 内容 |
| --- | --- |
| `arcadia_config` | 表示、投稿補助などの設定 |
| `arcadia_favorites` | お気に入りとNGワード |
| `ss-theme` | ライト・ダークテーマ |
| `style-control-bar-settings` | 本文スタイルバーの状態 |

設定JSONが破損している場合や、既知項目へ異なる型の値が保存されている場合は、その項目だけ既定値へ戻して起動します。正しい型の保存値と未知の追加項目は維持します。

名前、トリップ、パスワードの初期値は空欄です。入力した値は利用者のブラウザ内に保存されるため、共有PCでは自動入力を有効にしないでください。

## 開発用ファイル

- `fixtures/`: 実在作品を含まない合成HTML
- `tests/browser-runner.html`: 合成HTMLを使うブラウザ回帰テスト
- `改善作業台帳.md`: 改善項目、状態、完了条件、確認結果
- `段階改修台帳.md`: 段階改修の判断基準、実施順、完了記録
- `参考HTML/`: ローカル確認専用の保存HTML。Git管理外

テストの実行方法は `tests/README.md` を参照してください。npm、build、ESModulesは使用しません。

## 開発上の制約

- 配布物はUserscript 1ファイルを維持する
- お気に入りとNGワードはタイトルへの部分一致を維持する
- Arcadia固有のtable位置、class、URL、フォーム構造を互換境界として扱う
- 生の保存HTMLをGitへ追加しない
